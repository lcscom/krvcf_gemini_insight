2. Tech Docs & KB Deep Dive (Critical Outage Preventions)

🚨 NSX ALB: ESXi 시간 동기화 불일치(Time Skew) 문제

NSX Advanced Load Balancer Controller가 ESXi의 시간 동기화 문제로 인해 Time Skew를 겪으면 큐잉(Queuing)에 심각한 영향이 발생합니다. 이는 **로드 밸런싱 서비스 중단**으로 이어질 수 있습니다. vCenter 통합 전/후 NTP 설정을 철저히 점검해야 합니다.

[Source]

VCF 다운로드 도구(VCFDT) SSL 검사 시 TLS 신뢰 체인 관리

VCFDT를 사용할 때 SSL Inspection(보안 정책)이 적용된 환경에서 TLS 신뢰 체인(Chain of Trust) 문제가 발생할 수 있습니다. **VCF 업그레이드 전 반드시** 이 환경 구성을 확인하지 않으면 패치 다운로드에 실패하여 전체 업그레이드가 중단됩니다.

[Source]

NSX ALB IPv6: MAC Masquerade의 필요성

NSX Advanced Load Balancer에서 IPv6 사용 시 MAC Masquerade의 역할과 Layer 2 Scale In/Out 작동 방식을 이해해야 합니다. 대규모 환경에서 SE(Service Engine)의 스케일링이 정상적으로 작동하지 않으면 **서비스 가용성**이 저하됩니다.

[Source]

NSX ALB: 22.1.1 이전 버전에서 vCenter Cloud 업그레이드 시 고려 사항

레거시 버전(22.1.1 이전)에서 업그레이드 시 vCenter Cloud 구성에 대한 특별한 고려 사항이 필요합니다. 이를 놓치면 업그레이드 후 **vCenter와의 연동이 실패**하거나 Service Engine 배포에 문제가 발생할 수 있습니다.
