2. Tech Docs & KB Deep Dive (공식 문서 분석)

  • NSX ALB: vCenter 통합 장애 시 NTP 동기화 점검의 중요성

    VMware ESXi Time Sync으로 인한 Time Skew(시간 불일치)가 NSX ALB Controller의 큐잉(Queuing)에 악영향을 주어 치명적인 장애를 유발합니다. 설치 후 vCenter Discovery에 문제가 있다면 NTP 설정을 가장 먼저 확인해야 합니다.

    [Source: KB/Troubleshooting]
  • VCF SSO 긴급 복구: 관리형 vCenter Server 재설정 빠른 팁

    VCF SSO가 손상(Broken)되어 인증에 실패할 때, SDDC Manager의 관리 작업(Managed Operation)을 사용하여 vCenter Server를 재설정하는 절차가 공유되었습니다. 이는 치명적인 관리 접근성 문제를 해결하기 위한 현장 엔지니어의 필수 런북 항목입니다.

    [Source: Expert Tip]
  • NSX ALB: Service Engine 배치 Anti-affinity 설정 권장

    NSX ALB의 고가용성(HA) 확보를 위해 Service Engine(SE)이 동일한 ESXi 호스트에 배치되는 것을 막는 Anti-affinity 규칙 설정이 중요합니다. 설치 자동화 시 이 설정을 놓치면 단일 호스트 장애 시 서비스 중단을 초래합니다.

    [Source: Tech Doc]
  • NSX ALB: IPv6 및 Layer 2 Scale-out/Scale-in 복잡 구성 시나리오

    IPv6 VIP 및 듀얼 스택(IPv4v6) 환경 구성과, 특히 Layer 2를 이용한 SE Scale-out/Scale-in에 대한 상세 기술 문서가 업데이트되었습니다. 고성능/대규모 네트워크 환경 설계 시 Layer 2 Scale 관련 제약 조건을 반드시 검토해야 합니다.

    [Source: Tech Doc/IPv6 Case]

    [Source: Tanzu Security Policy]

    [Source: Avi Troubleshooting]
