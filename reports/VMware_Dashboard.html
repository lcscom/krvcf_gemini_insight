2. Tech Docs & KB Deep Dive (Critical Field Troubleshooting)

NSX ALB(Avi) 운영 문서의 주요 업데이트. 엔지니어는 이 문제를 모르면 장애에 취약합니다.

  • NSX ALB: 관리 네트워크 중첩(Overlapping Management Network) 경고: SE(Service Engine)의 관리 네트워크 중첩은 Controller와의 통신 문제를 야기하며, 이는 자동 복구/확장 기능을 마비시키는 치명적인 구성 오류입니다. 즉각적인 네트워크 재구성이 필요합니다. [Source]
  • NSX ALB: SE CPU 사용량 불일치(Disparity in CPU Utilization) 진단: 하이퍼바이저 상의 SE CPU 사용률이 비정상적으로 높거나 불균형할 경우, 이는 트래픽 분산 메커니즘(예: Round Robin)의 비균일성 또는 특정 SE의 과부하를 의미하며, 성능 병목 현상(Bottleneck)의 원인이 됩니다. [Source]
  • NSX ALB: 치명적 경고(`SE_SYN_CACHE_USAGE_HIGH`, `CONN_DROP_POOL_LB_FAILURE`) 분석: 이 경고들의 동시 발생은 SYN Flood 공격이나 급격한 세션 증가로 인한 Service Engine 리소스 고갈 상태를 나타내며, 즉각적인 커넥션 드롭(Connection Drop)과 서비스 중단으로 이어집니다. [Source]
  • Troubleshooting: 서버 플래핑(Server Flapping) 문제 해결: 백엔드 서버가 Health Check에 실패하며 Up/Down을 반복하는 '플래핑' 현상은 애플리케이션 가용성을 저해하는 주된 원인입니다. Health Monitor 설정(타임아웃, 간격)의 재검토가 필수적입니다. [Source]
